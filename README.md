# VCD BFA Senior Showcase

The website I designed and built for Kent State University's 2025 **Visual Communication Design BFA Senior Showcase**. It brings all 30 graduating seniors' design work together in one place.

**Live site:** https://jacob-nicholson.github.io/vcd-bfa-showcase/

## About the project

Each year, graduating VCD seniors exhibit their work at the Taylor Hall Gallery. I built the show's website from scratch in HTML, CSS, JavaScript and p5.js, using the show's branding and my classmates' portrait photography. Coding it by hand was faster and cheaper than a website builder, and it gave the seniors more control over how they were presented.

### Features

- **Interactive p5.js carousel.** Browse each senior's name, portrait and bio with the arrow buttons. The name panel collapses and expands between seniors while the background cycles through the show's colors.
- **Senior grid.** A collapsible, responsive grid of portraits, each linking to that senior's portfolio.
- **Mobile layout.** On small screens, the carousel steps aside and the grid takes over.

## Archive notes

This repo preserves the site as it was built in spring 2025. The only change is image compression: the portraits were resized and re-saved, taking the site from 151 MB to 15 MB with no visible difference.
